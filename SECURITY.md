# Security Policy

## Supported versions

| Version | Supported |
| :--- | :--- |
| 1.0.x | Yes |

## Scope

This repository is an agent skill: instructions, examples, and a package publish workflow. It does not run a service and it does not collect data.

Report a problem if you find:

- An instruction that would leak secrets, credentials, or private user data
- A publish workflow or config change that exposes a token
- A malicious link or payload introduced in the skill, docs, or issue templates

## Reporting a vulnerability

Do not open a public GitHub issue for an undisclosed security problem.

1. Open a private report: [Security advisories](https://github.com/grvmon/sniper-seo-geo-aeo/security/advisories/new).
2. Include what you found, how you triggered it, and the impact.
3. You should receive an acknowledgement within 7 days.

If private vulnerability reporting is not available on the repository yet, message [Gaurav Mongia on LinkedIn](https://www.linkedin.com/in/gaurav-a-mongia) with the same details. Do not post the details in Discussions.

## Out of scope

Ranking advice, citation rates, and content disagreements are product feedback. Use [Issues](https://github.com/grvmon/sniper-seo-geo-aeo/issues) or [Discussions](https://github.com/grvmon/sniper-seo-geo-aeo/discussions) for those.
