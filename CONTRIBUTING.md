# Contributing

Thanks for improving Sniper SEO + GEO + AEO.

## How to contribute

1. Fork the repository and branch from `main`.
2. Keep the change focused. Put audit and citation rules in `SKILL.md`. Update `README.md` when install, usage, or supported engines change. Note user-visible changes in `CHANGELOG.md`.
3. Open a pull request against `main`. The pull request template lists the checks.

Bugs and feature requests use the templates in Issues. Questions go in Discussions. Conduct is covered by [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md). Vulnerabilities are covered by [SECURITY.md](SECURITY.md).

## Publishing

Package metadata lives in `package.json`. Publishing to GitHub Packages runs from `.github/workflows/publish.yml` when a GitHub Release is published, and can also be started manually with `workflow_dispatch`.
